Overview

What FPGASim is, how the pieces fit, and where to find each design view.

1. What FPGASim is

FPGASim lets students write VHDL or Verilog in a browser and watch it run on an animated Terasic DE2-115 board (18 slide switches, 4 push buttons, 18 red + 9 green LEDs, eight 7-segment displays, a 50 MHz clock). It replaces the expensive physical board for learning and debugging, and adds things real hardware can't easily show: live waveforms, single-cycle stepping, and recording of every internal signal.

The design compiles with real, open-source simulators (GHDL for VHDL, Icarus Verilog for Verilog), so the full languages are supported. A generated "board testbench" connects the student's top-level ports to the virtual board and streams values to the browser in real time.

5. Glossary

DUT
Device Under Test: the student's top-level entity/module.
Wrapper / board testbench
Auto-generated HDL (fpgasim_tb) that instantiates the DUT, drives the clock and inputs, and prints outputs.
Batch / step
One request to advance the simulation by N clock cycles with given switch/key values.
VCD
Value Change Dump: a standard text file listing every signal change, viewable in GTKWave.
Active low
A signal that means "on" when it is 0. DE2-115 keys and 7-segment segments are active low.
Delta cycle
A zero-time simulation step used to settle combinational logic. Infinite delta loops indicate a combinational loop.
